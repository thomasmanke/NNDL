A trained network summarizes supervised data (images, labels) in terms of parameters (weights and biases).

Previously we looked at ways to ‘interprete’ the classification of a given image in terms of certain features.

Question

Can we understand the network and the function of individual neurons (without any image)?

Notice that this reductionist technique assumes that some aspects of neuronal fucntions can be understood detached from the network context (e.g.  edge detectors, colour filters etc)

Visualize Neuron Preferences

Rather than visualizing the neuronal weights it might be more interesting to visualize possible inputs that activate neurons maximally

Use training data

Find image patches (in training data) that maximally activate a neuron from a given layer and channel

Reference: Zeiler and Fergus (2014). Visualizing and understanding convolutional networks. Figure 2. Link

Important
  • early layers detect simple patterns/colors,
  • deeper layers detect objects/concepts

Optimizing Input Images

Rather than using pre-exisitng images or image patches we can also generate new synthetic images that maximally activate a neuron.

Interestingly this can be done using the same tools of backpropagation, but now extended to the image features itself (and not ust the parameters)

Mathematical Implementation - Activation Maximization

For each layer \(l\) and channel \(c\) we can define the mean activation (single scalar) for a given input image \(x\)

\[ J_{l,c}(x) = \frac{1}{HW} \sum_{ij} f_{l,c}(x) \]

  • Fixed: network parameters
  • Chosen: layer \(l\), channel \(c\)
  • Optimize: input image \(x\) to maximize \(J_{l,c}(x)\)
  • Regularize: enforce constraints on image \(x\) (smoothness etc)

\[ \underset{x}{\mbox{argmax}} \left( J_{l,c}(x) - \lambda R(x) \right) \]

Notes
  • c.f.loss minimization \(L(w)\): optimize \(w\)!
  • network parameters \(w\) fixed
  • gradient ascent: iterative optimization starting from random image
  • dependence on definition of \(J_{l,c}\) (other definitions possible)
  • dependence on regularization \(R(x)\) (smoothness, priors etc)
  • independent of data set !
Implementations
  • Lucid (TF 2018) distill.pub (Olah et al.)
  • Lucent (PyTorch 2020) (L. Kiat & T. Lieberum)
Uses
  • detect dead filters
  • compare models
